# 테스트 · 확인용 계정

팀 개발 DB 기준. **비밀번호는 저장소에 적지 않는다** (공개 저장소) — 팀 채널로 따로 전달한다.
앱 실행: `./gradlew bootRun` → 고객 http://localhost:8080 · 관리자 http://localhost:8080/admin/login

## 고객 로그인 방법

고객 앱은 아이디·비밀번호 없이 **휴대전화 인증번호**로 로그인한다.
문자 발송 서비스를 아직 붙이지 않아 인증번호는 문자 대신 **서버 로그**에 찍힌다.

```
[SMS] 010-0000-0001 ← [명품익스프레스] 인증번호 [123456]를 입력해 주세요.
```

## 1. 테스트 계정 — 직접 눌러 보는 용도

| 구분 | 로그인 | 비고 |
|---|---|---|
| 관리자 | 아이디 `admin` | 운영자 권한. 첫 로그인 비밀번호 변경 없이 바로 사용 |
| 고객 | 휴대폰 `010-0000-0001` (테스트고객) | 견적 요청 · 확정 · 취소 · 후기 · 채팅 등 데이터를 바꾸는 동작은 이 계정으로 |

- 확인이 끝나면 `docs/erd/cleanup-test-data.sql` 을 실행해 테스트고객으로 생긴 데이터(견적 · 예약 · 후기 · 채팅 · 알림)를 지운다. 계정은 남는다.
- 마스터 계정 `master` 는 공용 계정이라 테스트에 쓰지 않는다 (첫 로그인 때 비밀번호를 바꿔야 함).

## 2. 보기용 추천 계정 — 시안처럼 채워진 화면 확인

팀원이 넣어 둔 예시 회원(ID 900001~). **보기만 하고 버튼(확정 · 취소 · 후기 작성 · 채팅 답장 등)은 누르지 않는다** — 예시 상태가 바뀌어 다시 볼 수 없게 된다.

| 회원 | 휴대폰 | 볼 수 있는 화면 |
|---|---|---|
| 김무브 | 010-4321-8765 | 홈 · 내 이사의 **견적 도착** 카드, 견적 상세 · 견적서 원본 |
| 김코드 | 010-5678-1234 | **예약 확정**(12/8, 계약금 결제 완료) · 지난 **이사 완료** · **후기** |
| 강준호 | 010-9081-3362 | 견적 도착 (김무브와 같은 상태, 다른 내용) |
| 홍길동 | 010-1234-5678 | 예약 확정(11/11, 계약금 결제 대기) · 상담 **대기 중 채팅** |
| 윤채원 | 010-2466-8103 | 견적 **검토 중** (송민재 010-8642-5179 · 한예린 010-1937-6405 도 같음) |
| 임지수 | 010-9901-7722 | **취소된 예약**이 있는 예약내역 |
| 박철수 | 010-7788-2200 | 이사 완료 + 후기 (사장님 답변 없음) |

관리자(`admin`)로 들어가면 위 회원들의 견적 · 예약 · 후기 · 채팅이 관리자 화면에 모두 보인다.

> 예시 데이터는 날짜가 지나면 상태가 바뀐다 (예: 견적 만료, 이사일이 지난 예약은 이사 완료). 화면이 다르게 보이면 관리자 화면에서 상태를 먼저 확인한다.
