# 관리자 화면 디자인 기준 (v2)

관리자 화면을 사용자 앱과 같은 기준으로 다듬기 위한 규칙입니다. 화면 구성과 기능은 스토리보드(SCR-A-001~023)를 그대로 따르고, **가독성·색·아이콘만** 이 기준으로 맞춥니다.

- 진행 방식: 화면마다 **시안(`/dev/admin/redesign/…`) → 확인 → 실제 적용** 순서로 하나씩 바꾼다. 현재 화면과 시안 비교: `/dev/dev/compare-admin` (local 전용)
- 공통 파일: `templates/fragments/admin-layout.html`(헤더·하단 탭), `templates/fragments/admin-bare.html`(헤더·탭 없는 화면), `static/css/admin/admin-v2.css`, `static/images/admin/icons-v2.svg`

| 적용 현황 | 화면 |
| --- | --- |
| ✅ 적용 | 공통 헤더·하단 탭·아이콘·색, 전체 메뉴 메뉴 검색, 견적 관리(SCR-A-001, 만료 상태 포함)·견적 수정(SCR-A-002)·견적서 등록(SCR-A-003/004, 3단계), 예약 관리(SCR-A-011), 리뷰 관리(SCR-A-012), 알림 관리(SCR-A-013~015, 탭 2개로 통합), 알림 패널(SCR-A-019), 전체 메뉴·메뉴 검색(SCR-A-017·018), 상단 알림(푸시 배너), 회원 관리(SCR-A-023), 대시보드(SCR-A-016), 스플래시·로그인·비밀번호 변경(신규), 채팅(SCR-A-005~010: 상담함·채팅방·채팅 설정·채팅 시작 화면·챗봇 답변 관리·자주 쓰는 답변), 일정(SCR-A-020 예약 일정 · SCR-A-022 일정 관리, A-021 개인 일정은 뺌) |
| ⏳ 시안 | 없음 — 새로 고칠 화면은 같은 방식(시안 → 비교 → 적용)으로 |

| 섹션(카드) 제목 | 17px Bold | `#1a1a1a` |
| 목록 이름·본문 | 15px SemiBold | `#292929` |
| 보조 문구 | 14px | `#555` |

12px 미만은 쓰지 않는다.

## 2. 색 (사용자 앱 `css/user/app.css :root` 와 같은 값)

| 용도 | 클래스 | 색 |
| --- | --- | --- |
| 완료·기본 | `tone-green` | `#346538` / `#eef4f0` |
| 최종 단계 (견적 확정 등) | `tone-solid` | 흰 글자 / `#346538` |
| 승인·진행 중 | `tone-sage` | `#537557` / `#f0f4ea` |
| **조치 필요** (검토 대기, 결제 대기) | `tone-orange` | `#f5831a` / `#fff3e6` |
| 취소·삭제 | `tone-danger` | `#d8663d` / `#fff1e9` |
| 막대 그래프 | `bar-green` · `bar-sage` · `bar-orange` · `bar-muted`(만료, 연회색) | 위와 같음 |
| 배경 · 구분선 | | `#f7f8f6` · `#e5e7eb` / `#eef0ee` |

- 파랑·보라·빨강 등 사용자 앱에 없는 색은 쓰지 않는다.
- 주황은 **관리자가 처리해야 하는 것**에만 쓴다.
- **목록의 상태는 칩**(`.chip`): 높이 24px · 12px Medium · **연한 배경 + 색 글씨, 채움 없음** → 등록 같은 주요 버튼(초록 채움)보다 위계가 낮다.
  - `chip-review` 검토(조치 필요) = 주황 글씨 / 연주황 · `chip-progress` 승인(진행 중) = 회색 / 연회색 · `chip-done` 확정(완료) = 초록 / 연초록 · `chip-cancel` 취소 = 붉은 주황 / 연주황 · `chip-expired` 만료 = 연회색 글씨 + 회색 테두리(배경 없음)
  - 진행 중은 회색으로 두어 주황·초록과 확실히 구분한다. 진한 채움 칩은 쓰지 않는다.
- 색 배경 상자(`tone-*`)는 아이콘 타일에 쓴다.

## 3. 아이콘

- `icons-v2.svg` (Lucide, ISC 라이선스). id 는 기존 `icons.svg`(삭제됨) 와 같은 이름 (`#i-calendar`, `#i-document` …) + 추가: `calendarCheck` `clipboard` `filePlus` `plus` `filter` `card` `chart` `messages` `phone` `chevronLeft` `chevronRight`.
- 크기: 헤더·하단 탭 24px, 카드 타일 24px(44px 타일 안), 목록 동작 버튼 19~20px.
- 선 굵기는 CSS 로 정한다 (기본 1.9, 선택된 하단 탭 2.3). 심볼에 stroke-width 를 넣지 않는다.
- 현황 카드·전체 메뉴의 아이콘은 상태 색 타일(`tone-*`, 44px, 모서리 14px) 위에 둔다.

## 4. 구성 요소

| 요소 | 규칙 |
| --- | --- |
| 헤더 | 사용자 앱 브랜드 마크(집+미소, **27px** — 사용자 앱 헤더와 동일) + "명품익스프레스"(16px ExtraBold) + "관리자" 배지 + 알림만, 높이 64px. **검색 아이콘은 두지 않는다** |
| 메뉴 검색(SCR-A-018) | 헤더가 아니라 **'전체' 메뉴 맨 위 검색창**("메뉴 이름이나 초성으로 검색")에서 연다. 화면 안 돋보기는 그 화면 목록 검색 전용이라 헷갈리지 않게 하기 위함 |
| 하단 탭 | **사용자 앱 `.bottom-nav` 와 같은 모양**: 흰 배경, 위 모서리 27px, 그림자 `0 -3px 20px 4px rgba(0,0,0,.1)`, 높이 86px + 안전 영역. 아이콘 27px · 이름 12px. 비선택 = **연한 회색** 아이콘·글자(`#a3a8a4` · `#9a9f9b`), 선택 = 아이콘 뒤 배경 상자 없이 **아이콘 모양 안을 초록 18% 로 채움**(사용자 앱 `b676d.svg` 등과 같은 값) + 초록 선 1.8 + 초록 SemiBold 글자 — 선택·비선택이 확실히 구분되게. "챗봇" → "채팅" |
| 화면 상단 | 1행: **페이지 제목만**(22px, 위계를 위해 다른 요소를 두지 않음), 아래 여백 20px / 2행: 왼쪽 분류 필터 · 오른쪽 **배경 없는** 검색 아이콘(22px) + **아이콘 없는 초록 채움 버튼** "등록"(높이 36px, 14px Bold) |
| 분류 필터 | 사용자 앱 일반/쉬운 토글과 같은 **세그먼트**: 회색 트랙(`#eef0ee`), **내용만큼의 폭**(왼쪽 정렬), 높이 32px · 14px SemiBold, 선택은 흰 알약 + 초록 글자, 나머지 회색. **건수는 넣지 않는다**(분류별 현황에서 확인). 상태 이름은 짧게(검토·승인·확정) |
| 검색 | 돋보기 아이콘. **날짜와 이름 둘 다** 검색. 날짜는 26.03.25 · 2026-03-25 · 260325 · 2026.03(연월) · 3.25 · 0325(월일) · 3월 25일 모두 인식하고, 숫자를 입력할 때마다 결과가 바로 좁혀진다 (`estimate.js` `dateMatcher` 를 다른 목록도 그대로 쓴다) |
| 목록 | 건수가 많아질 수 있으므로 **한 줄 리스트**(흰 카드 안에 구분선): 머리글 12px, 상태 배지 · 이름 15px · 날짜 13px · 동작 버튼. 카드형 큰 목록은 쓰지 않는다. **칸 사이 간격은 고르게**: 한 칸만 1fr 로 남는 폭을 몰아주지 말고 내용 길이에 맞춘 비율(예: 회원 관리 `1fr_1.6fr_1fr_0.9fr`)로 나눈다 |
| 하단 고정 버튼 | `sticky bottom-[var(--nav)]`, 하단 탭과 **20px(pb-5)** 띄움. 배경은 단색 띠 대신 위로 갈수록 투명해지는 그라데이션(`bg-linear-to-t from-[#f7f8f6]`). 안내 알약(확대 안내·저장 완료)은 버튼 바로 위 가운데 |
| 바텀시트 · 시간 선택 | 시트는 **하단 탭까지 덮는다**(어두운 배경 `inset-0`, 패널은 맨 아래, 위 모서리 24px, 손잡이, 아래 여백 `20px + var(--safe-bottom)`). 머리: 왼쪽 제목 18px + 오른쪽 X, 아래: 넓은 `btn-primary`. 시간 선택은 **휠 하나에 가운데 선택 띠 하나**(오전·오후 / 시 / 분, **3줄 높이 132px**, 스크롤 맞춤, 위아래 흐림) — 기준 구현: 채팅 설정(`admin/chat/settings.html`)의 시간 시트. 기본 `select` 상자 여러 개는 쓰지 않는다. 시작~종료처럼 범위를 정할 때는 설정 화면에 **두 줄('시작 시간 … ›', '종료 시간 … ›')**로 나누고, 각 줄이 그 시각만 고르는 시트(제목 + 휠 + [완료])를 연다 — 시트 안에 시작·종료 탭이나 칸을 두지 않는다 |
| 단위 붙은 입력칸 | 원·층·톤 등 단위는 입력칸 안 오른쪽. 입력칸 기본 스타일은 `@layer components` 에 두어 `pr-9` 같은 유틸리티가 덮어쓸 수 있게 한다 (층 없는 CSS 는 Tailwind 유틸리티보다 우선해 글자와 단위가 겹친다) |
| 카드 | 흰 배경, 모서리 20px, 그림자 `0 2px 12px rgba(26,26,26,.05)` |
| 편집 화면 카드 | 입력칸이 많은 편집 화면(챗봇 답변 수정·채팅 시작 화면 편집 칸)은 **흰색 90% + 연한 테두리**(`bg-white/90 ring-1 ring-inset ring-[#e5e8e4]`, 그림자 없음) — 목록·메뉴 카드보다 덜 튀게. 칸이 하나뿐이면 바깥 카드 없이 입력칸 자체를 카드 모양으로 |
| 입력칸(편집) | 회색 채움 상자(`#f5f6f4`, 모서리 12px, 포커스 흰 바탕 + 초록 2px) · 이름표 15px SemiBold · 글자 수는 칸 안 오른쪽 아래에 **입력 중에만** · 필수 표시(*) 없음 · 아래 고정 [저장] 하나(바뀐 것이 있을 때만 활성) |
| 채팅(메신저형 예외) | 상담함은 카드·구분선 없이 바탕 위 한 줄씩(프로필 원 48px · 이름 16px · 안 읽은 수 주황). 채팅방은 하단 탭 숨김(`data-hide-nav`), 고객 말풍선 흰색 · 관리자 진초록 · AI 연회색, 안내 줄 연회색, 연달아 보낸 고객 말은 첫 말풍선에만 프로필 원 + 이름. 입력은 떠 있는 흰 상자(첨부 · 입력 · 비었을 때 자주 쓰는 답변 / 글자를 쓰면 ↑ 보내기) |
| 달력(예약 일정) | 월 달력 + 고른 날 목록, [오늘] · [달력 접기]. 날짜 아래: 예약은 건수만큼 크림색 점(`#cdbf86`, 최대 3) · 휴무는 회색 '휴무'. 빨강은 일요일·공휴일 숫자 전용, 진한 초록은 고른 날·다음 이사('2시간 후' 꼬리표)에만. 목록은 박스 한 줄(시간 · 이름 · 유형 / 출발 → 도착), 결제 상태는 예약 상세에서 |
| 페이지 이동 | 36px 원형, **약하게**: 선택은 연초록 배경 + 초록 Bold 글씨, 나머지는 회색 글씨만(배경·테두리 없음) |

## 5. 신규 화면 (ERD 수정안 Q10 — 관리자 로그인)

| 화면 | 시안 | 내용 |
| --- | --- | --- |
| 스플래시 | `/admin/login` 첫 진입 시 (세션당 1회, `?splash=hold` 멈춤 · `?splash=off` 생략) | 사용자 앱 스플래시와 같은 모양(초록 배경 · 크림색 로고 · 브랜드 글꼴) + "관리자" 표시 |
| 로그인 | `/admin/login`, `?state=error` | 아이디(최대 20자) · 비밀번호(보기/숨기기). 두 칸을 채워야 [로그인] 활성화. 불일치 시 입력칸 테두리 붉은 주황 + 안내 문구. 하단 한 줄 "비밀번호를 잊으셨다면 담당자에게 문의해 주세요." |
| 비밀번호 변경 | `/admin/password` | 첫 로그인(초기 비밀번호, `PW_CHANGED_AT` 없음) 시 강제. 현재 · 새 · 새 확인. 조건 3개(8자 이상 · 영문·숫자 포함 · 새 비밀번호 일치)가 맞으면 초록으로 바뀌고 [변경하고 시작하기] 활성화 |

- 헤더·하단 탭이 없는 화면은 `fragments/admin-bare.html` 을 쓴다 (반응형·안전 영역은 같음).
- 입력칸 `.field-input`(높이 56px · 모서리 14px · 포커스 초록 2px · 오류 붉은 주황), 큰 버튼 `.btn-primary`(높이 56px, 비활성 회색).
- **문구는 최소한으로**: 라벨이 있으면 같은 말을 placeholder 로 반복하지 않는다. 화면 제목 아래 부연 설명, 라벨 옆 괄호 설명(예: "(사번)")은 넣지 않는다.
